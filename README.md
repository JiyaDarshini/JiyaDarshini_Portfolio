# Jiya Darshini - Interactive Portfolio

An interactive, responsive portfolio website for **Jiya Darshini** (Computer Science & Business Systems Student, Developer, Problem Solver, and Creative Thinker).

## Features

- **Full-Bleed Illustrated Artwork Background**: The original portrait illustration serves as the full-screen canvas.
- **Interactive Cursor-Tracking Eyes**: Merged multi-state eye overlays (`CENTER`, `UP`, `DOWN`, `LEFT`, `RIGHT`) that dynamically and smoothly follow the visitor's cursor across the entire screen.
- **Overlaying Portfolio Content**: Left-aligned hero content with clean typography and action buttons.
- **Interactive Modals**: Smooth slide-over modals for *Projects*, *Skills*, *About*, and *Contact*.
- **Responsive Layout**: Designed for seamless viewing across mobile, tablet, laptop, and 4K displays.

## Tech Stack

- **HTML5 & CSS3** (Vanilla CSS, custom design system, glassmorphism)
- **Vanilla JavaScript** (requestAnimationFrame interpolation engine, dynamic responsive layout tracking)

## Live Preview & Setup

Simply open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.
